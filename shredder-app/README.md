# 🗑️ 感情のゴミ箱 - マインド・シュレッダー

## 概要 (System Overview)
「感情のゴミ箱」は、日々のストレスやモヤモヤ、イライラをテキストとして書き出し、「シュレッダーにかける」ことで視覚的に破壊し、心理的なスッキリ感を得るためのシンプルなWebアプリケーションです。
入力した文字数に応じて、シュレッダーの演出が4段階（弱・中・強・激）で派手になる機能を搭載しています。

## 用途 (Use Case)
* 日常の小さなイライラやストレスの解消
* 誰にも言えない愚痴や不満の安全な吐き出し口（※入力データはサーバー等に一切保存されません）
* 気持ちをリセットして次の作業に集中するための、手軽なマインドフルネス・ツール

## 技術スタック (Tech Stack)
* **フロントエンド**: HTML5, CSS3, Vanilla JavaScript
* **サーバー**: Nginx (Alpine Linuxベース)
* **インフラ**: Docker, Docker Compose

## 実行方法・Dockerコンテナの起動 (How to Run)

このアプリケーションはDockerコンテナ上で動作します。ホストマシン（ご自身のPC）にDocker環境がインストールされていることを前提としています。

### 1. プロジェクトの準備
プロジェクトのディレクトリ構成が以下のようになっていることを確認してください。

```text
shredder-app/
├── docker-compose.yml
├── Dockerfile
└── html/
    ├── index.html
    ├── style.css
    └── script.js
```

### 2. Docker Desktop の起動
Windows または Mac をご利用の場合は、**Docker Desktop** を起動し、エンジンが稼働中（Engine running）になっていることを確認してください。

### 3. コンテナのビルドと起動
ターミナル（またはコマンドプロンプト、PowerShell）を開き、プロジェクトのルートディレクトリ（`shredder-app`）に移動して以下のコマンドを実行します。

```bash
docker-compose up -d
```
※ `-d` オプションにより、コンテナはバックグラウンドで実行されます。

### 4. ブラウザでアクセス
コンテナが正常に起動したら、ホストPCのブラウザから以下のアドレスにアクセスします。

🔗 **http://localhost:8080**

### 5. コンテナの停止
アプリの利用を終了し、コンテナを停止・削除する場合は、同じディレクトリで以下のコマンドを実行します。

```bash
docker-compose down
```

## 使い方 (Usage)

1. ブラウザでアプリにアクセスすると、テキストエリアが表示されます。
2. 今抱えているモヤモヤやイライラを思いのままに入力してください。
3. 入力した **文字数に応じて下部の「レベル」が変化** し、ボタンの色やテキストも連動して変わります。
    * **レベル: 弱 (～20文字)**: 通常のシュレッダー
    * **レベル: 中 (21～50文字)**: 少し強めのシュレッダー
    * **レベル: 強 (51～100文字)**: 紙くずだけでなく、**入力した「文字そのもの」**も飛び散ります
    * **レベル: 激 (101文字～)**: 超・激怒モード。画面全体が揺れ、背景が赤く光り、大量のパーティクルが飛び散ります。
4. **「シュレッダーにかける」ボタンをクリック**すると、テキストが消え去り、設定されたレベルに応じた破壊アニメーションが再生されます。
